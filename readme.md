## Descripción

Se trata de una aplicación web básica de gestión de tareas que  usa Node.js, NPM y express.

## Objetivo

Aplicar los conceptos fundamentales de administración de paquetes y exponer funcionalidades mediante servicios REST y SOAP.

## Instalación


Usar el siguiente comando en terminal para obtener la aplicación.
```bash
git clone <https://github.com/Alanv871/Actividad1_DesarrolloBasadoEnPlataformas>
```

## Ejecución


```bash
[npm run dev]  Para iniciar el servidor
[npm run test]  Para hacer las pruebas con jest
[npm run lint]  Para utilizar lint
```


## Funcionalidades / uso


Al escribir el comando "npm run dev" se iniciará un servidor local al que se puede acceder usando localhost/3000 en un navegador web.

## Pruebas

Usando "npm run test" se pueden hacer pruebas que simulan la creación de una tarea, la consulta de las tareas existentes, actualizar una tarea y eliminar una tarea.

## Análisis de calidad de código

Se puede realizar un análisis estático usando "npm run lint".

## Estructura general del proyecto

El código del proyecto se organiza de la siguiente manera:

```text

|-- [test] *Donde se encuentran los tests que se pueden realizar con Jest
```
